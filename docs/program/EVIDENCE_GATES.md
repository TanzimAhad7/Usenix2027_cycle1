# Proof obligations: when can the eventual paper make a claim?

For every headline finding, collect the following **from one linked workflow, not from unrelated old studies**:

| Step | Evidence to retain | Mistake to avoid |
|---|---|---|
| Owner's permission | Root task, applicable grant, scope/use limits, requirement/alternative | Taking a model-generated claim as permission |
| Legitimate needed facts | Actual original eligible tool/peer input | Destroying the facts while removing suspicious text |
| Attack/exposure | Exact allowable attacker surface, delivery, opportunity | Counting undelivered payloads as attacks |
| Proposal | Agent-created ordered operation IDs with complete arguments | A forced illegal action presented as natural behavior |
| Reference | Exact guard input and lineage, original and descendants | Treating an approximate summary as the actual reference |
| Decision | Actual judge call, route, exemption, blocked/released IDs | Old reason text as a current judge result |
| Dispatch/commit | Actual executor event, receipt *and separate state delta* | A success string or duplicate receipt as proof of charge |
| Independent label | Authorized/forbidden/UNKNOWN plus annotator review | Final success or EXACT-ONE call as universal authorization |
| Continuation | Any early harm, later legal completion, appropriate deferral | A refund or final good action erases earlier unauthorized effect |
| Counterfactual | Matched valid intervention, placebo, necessary facts/authority preserved | Reference-only surgery called whole-agent rollback |
| New transfer | Fresh causal structures and pre-outcome prediction | New names or repeated calls treated as independent structures |
| Reporting | All cells, enrollment counts, unknowns, failures, version, costs | Only showing selected attacks where a defect occurred |

Use `docs/program/REVIEWER_TO_EXPERIMENT_MATRIX.csv` to map each reviewer concern to the exact output needed; all `OPEN` statuses remain open until *actual new evidence* is present.
