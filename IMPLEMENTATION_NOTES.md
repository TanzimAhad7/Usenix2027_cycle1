The new namespace is `reconciled_study`, so extracting the archive does not replace older experiment modules or raw result directories. Runtime references to original source-directory names in assets are provenance strings only; execution never opens those old locations. All required bytes are bundled.

Published source identity is verified. Qualification is narrower than an external replication: the eight CPU pairs use authenticated states/judge tapes, with declared derived exact-match and block-next controls. The latter's next actor call is a fixed routing probe. Fresh bounded transport probes compare published-style logprob requests to the archived adapter on fixed candidates/common references. They do not reproduce the published paper's cross-model benchmark. Material profile differences and unsupported interfaces stay recorded. Archival O96 does **not** inherit the published-probe logprob change.

CPU/mocked executions are engineering evidence only. A full mock sweep may complete legal goals because the fixture deliberately emits legal residual actions; that is not evidence of model capability. A separate controlled-overpay test proves that the archived partial-release path can commit 12 under a known fixture, that canonicalized complete release stays at 10, and that the trusted ledger contains the excessive continuation. Those actions are explicitly scripted and are not counted as new autonomous attacks.

E3 equivalence is evaluated only over captured inputs/routes up to the first response divergence. Different model outputs naturally produce different later inputs. Native tool-call IDs are not erased to make a pair look equal. Runtime-only mechanism state is retained for audit. If a supposed matched pair differs before a model response, the certificate rejects the hidden-cause interpretation.

No generated report claims causality, novelty, prevalence, acceptance readiness or full defense-class failure. Real model results require the frozen interventions, protection/negative cases and human semantic review.

The bundled design and allocation are the approved preimplementation records, retained unchanged for planned-versus-actual provenance. Their prospective labels do not describe the implementation status of this code delivery. The executable protocol, code and engineering validation are now present; scientific model slots remain unexecuted.
