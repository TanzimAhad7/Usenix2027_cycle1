# Primary literature sources and inspection provenance

See root `provenance/LITERATURE_FILES.csv` for official/author URLs and hashes of the versions previously inspected. Reading scope is recorded in `provenance/independent_audit/reading_and_code_coverage.md` and the native engine's `docs/FULL_PAPER_READING.md`. Publication PDFs are obtained from their primary sources; no old research checkout is required. The user-supplied manuscript, review text and incident PDF remain bundled in `references/`.

This catalog is not a new literature reading or independent replication. Recheck the actual version and relevant method/artifact before claiming novelty. Referenced external code not present here is a research dependency of a selected comparison, not silently treated as implemented.
