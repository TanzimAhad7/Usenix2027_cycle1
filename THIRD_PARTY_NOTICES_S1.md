# Source attribution and preservation

The unmodified AttriGuard implementation, release drivers, pipeline factory and release README under `s1_reference_study/vendor/` come from the retained public artifact associated with He et al., *AttriGuard: Defeating Indirect Prompt Injection in LLM Agents via Causal Attribution of Tool Invocations*, USENIX Security 2026. Artifact: https://zenodo.org/records/20308739 . Exact retained release ZIP and individual file hashes are in `vendor/SOURCE_IDENTITY.json`.

The provided attribution is retained. No separate license text was available among the selected retained release members; this package does not invent a license or claim authorship of those files.

AgentDojo 0.1.35 and its dependencies remain installed dependencies. Their native source identities are checked. No native Slack tool is replaced with a simulated reimplementation in this study.

The selected completed-run records under `origin_data/` preserve this project's original evidence. Membership is checked against the retained full-run checksum manifest. The original archive is identified by SHA-256; the subset does not constitute a digital signature or new independent attestation.

The serving ownership/cache helper was reused from this project's preceding native-release implementation and retains its source docstring. All other diagnostic integration, controls, CPU tests, instrumentation wrappers, controller and analysis are supplied by this implementation. No import depends on a rejected-submission directory, another repository, or the model-cache project's code.
