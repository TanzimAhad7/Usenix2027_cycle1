# Research decision register

Append a new JSON object to `decisions.jsonl` when a real decision is made. The initially empty register is intentional; no scientific decision has been fabricated by packaging.

Each entry records decision ID, evidence snapshot and primitive row IDs, route, claim and necessary links, nearest-work objection, source/runtime status, independently allowed/denied/unknown effects, enrollment/reachability counts, intervention validity, strongest protected case, complete-workflow cost, two discriminating next-test outcomes, actual result and reason to retain/narrow/pivot. Preserve amendments and superseded decisions.

Current implementation can reproduce inherited frozen quantities and run the R/B diagnostic. These facts are not an H24 result, completed human adjudication or a frozen confirmation design.
