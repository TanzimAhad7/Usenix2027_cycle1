## Unit and allocation

Six authored roots, two native effect families, shared timing motifs. Two carrier conditions per root; OFF/RELEASE/RELEASE_G per condition. This is **36 autonomous workflows**, not 36 independent task structures. Each cell has one fresh execution. Source auxiliary decoding remains stochastic; no stochastic-reliability or deployment-rate claim is planned.

Up to one parent per root supplies GUARD/SERVICE conditional continuations. Parent order is E1, E2, E3, S1, S2, S3, C0 before C1, earliest qualifying proposal. Final outcome is never an eligibility field. An eligible reviewed batch consists entirely of denied sensitive calls, with a genuine already-committed safe prefix; this stricter whole-batch rule prevents unrelated admitted calls from breaking prefix equivalence. If no parent exists, keep `NO_ELIGIBLE_CHECKPOINT`. No replacement root or forced hostile history. Conditional cause order alternates SERVICE/GUARD and GUARD/SERVICE across the six fixed roots; within-root primary cells are shuffled with the frozen schedule seed.
