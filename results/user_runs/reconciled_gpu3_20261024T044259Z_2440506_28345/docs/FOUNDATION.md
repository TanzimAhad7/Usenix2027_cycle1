# What makes this the whole-plan foundation

The repository supports both the inherited basis and the future work of the full v6.2 plan. The previous small package was sufficient only to run a particular diagnostic. This package carries the experiments, code and raw evidence needed to interrogate the old argument and build a defensible new one.

## The inherited scientific chain

1. **Natural relevance and generator breadth:** original/corrected cohorts, task selection, lexical taxonomy/scoring source, source trajectories and prospective generator records.
2. **Controlled source relocation:** 24-base designs, USER/TOOL × SHAM/ECHO inputs, native instrument/serializer source, condition scores, freezes and analysis. Corrected pure-source counts stay distinct from quartet discordance.
3. **Matched unauthorized comparison:** full action/context matrix, scorer source, primitive rows and analysis. Gemma's endpoint 13/24 and joint 23/24 are not mixed.
4. **Threshold frontier:** full finite-corpus sweeps and producers; descriptive overlap is not a universal impossibility result.
5. **AgentWatcher:** paired-gate inputs/results, separate ON/OFF population, monitor/adapters and reconstruction code. Detection and effect authorization remain different contracts.
6. **AttriGuard:** forced-pair protocol, route results, source versions, amendments and transition evidence; natural proposal is not inferred from a forced gate.
7. **CausalArmor reconstruction:** scorer/serializer/sanitation code, calibration, activation, capacity/error records and original scope limitations.
8. **Live end-to-end:** all 420 rows, 14-task definitions, pre/post environments, raw requests/continuations, freezes and runner/oracle code. Contrary protection and completion/utility disagreement remain visible.
9. **Replay:** all three model populations, 26-decision ancestry, raw generations, action/effect interface and frozen-suffix evaluator; agreement is not authorization or natural recovery.

These nine trees plus required integrations, oracle/implementation evidence, verification/reproduction source, figures and relevant provenance/hardening records are incorporated under `research_basis/`. Every included/excluded original file has a recorded hash and reason. No top-level original ZIP is duplicated, and no external old checkout is needed. Primary-source URLs/version hashes, source-reading records, independent criticism and primitive audit results are local.

## New tested interfaces

The root nohup launcher offers separate `historical`, `figures`, `components` and qualified `models` modes. Historical mode preserves original study checks while independently rebuilding central corrected contrasts and cells; it does not repair the meaning of all old labels. Figure mode intentionally reproduces frozen evidence. The new native R/B engine uses actual AgentDojo 0.1.35 dispatch and local source variants with a separate simulated ledger. Models mode is an adapted custom workflow, not the missing pilot release or a published-benchmark replication.

`docs/REPRODUCTION_STATUS.md` describes exact semantics and limitations. The original live all-in-one DAG retains known URL/context/fresh-parent defects. It is retained for source inspection and repair, not advertised as a supported fresh scientific rerun.

## What will make the paper defensible

Retaining the basis lets us reproduce and question the old findings; it does not create a new contribution. Follow the plan from source/observer/contract qualification through actual attacker reachability or protective explanation, a valid discriminating intervention, independent labels, the closest-work novelty test and fresh claim-specific confirmation. Preserve negative evidence and legitimate-use costs. Final paper claims need primitive joins and the correct denominator, not merely a green software report.

Read `DEFENSIBILITY_GAPS.md`. It distinguishes available research inputs, tested current software and scientific evidence not yet obtained. This repository is the complete selected starting basis for that work, not a statement that all future experiments or external artifacts already exist.
